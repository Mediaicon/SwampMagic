Swamp Magic is a Southern Gothic investigation RPG.

The player forms beliefs rather than discovering objective truth.

Knowledge has consequences.

Awareness replaces sanity.

Protected Mysteries are protected.

The Design Authority Document is canonical.


Rules

1. Design Authority is authoritative.

2. Protected Mysteries may not be resolved.

3. One AI writes code.

4. Others review.

5. Investigation > Combat.

6. Belief > Truth.

7. Contradictions are content.


One AI writes code.

Other AIs review.

All major decisions are recorded.

Repository State Rule

All reviewers must treat the current repository as authoritative.

Reviews may not rely on previous repository states.

When asked to review, reviewers must explicitly confirm they have reviewed the current version of all referenced files.

If current repository contents conflict with previous reviews, repository contents take precedence.
